# 데모 계정 목록

시드 스크립트(`scripts/seed_demo_data.py`)가 만드는 데모 세상입니다.
비밀번호는 **전부 `test1234`**.

## 계정

| 이메일 | 닉네임 | 역할 |
|---|---|---|
| test1@freshrun.com | 한강크루장 | **크루장** (한강 새벽 러닝 크루), 코스 2개(공개1·비공개1) 소유 |
| test2@freshrun.com | 러닝러버 | 크루원, test1과 맞팔, 코스 1개, 북마크 1개 |
| demo1@freshrun.com | 새벽러너* | 크루원, 인기 코스("뚝섬 순환") 주인, 팔로워 다수 |
| demo2@freshrun.com | 한강질주 | 크루원 |
| demo3@freshrun.com | 뚝섬바람 | 크루원 (RSVP 미정) |
| demo4@freshrun.com | 마포페이서 | 크루원 (RSVP 불참) |
| demo5@freshrun.com | 야간비행 | **가입 신청 pending** (크루장 신청 목록 화면 확인용) |

\* 닉네임이 선점된 경우 숫자가 붙을 수 있음 (예: 새벽러너84)

## 시딩된 세상

- **크루**: "한강 새벽 러닝 크루" (승인제, 멤버 6명 + pending 1명)
- **공지 2개**: 토요 정기런(러닝 일시·장소·RSVP 마감 有, 참석3/불참1/미정1 투표됨) + 일반 공지
- **러닝 기록**: 멤버들에게 최근 2주 분산 (3~10km) → 크루 피드·주간 랭킹·통계 살아있음
- **코스**: 공개 3개(좋아요·댓글 달림) + 비공개 1개(크루 피드에서 route_summary null 확인용)
- **팔로우**: test1↔test2 맞팔, 데모 유저들 ↔ test1 등 8건 → 팔로잉 피드 확인 가능

## 확인 포인트 (test1으로 로그인 시)

- 홈: 주간 통계, 팔로잉 피드 (러닝러버·새벽러너의 코스)
- 크루 상세: 러닝 피드, 랭킹, 공지+RSVP 집계, 가입 신청 1건(야간비행)
- 코스 피드: 좋아요/댓글/북마크 표시

## 재실행

`python scripts/seed_demo_data.py` — 멱등(감지-스킵)이라 몇 번 돌려도 중복 생성 없음.
**삭제는 하지 않으므로** test1/test2의 실제 기록은 안전합니다.
